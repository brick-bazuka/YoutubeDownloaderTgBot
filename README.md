**🎬 YouTube Downloader Bot
Telegram-бот для скачивания видео и аудио с YouTube.**

👉 Бот: [@yt_audio_video_download_bot](https://t.me/yt_audio_video_download_bot)

📥 Как пользоваться
🎥 Скачать видео
Отправьте команду с ссылкой:

```text
/download_video https://www.youtube.com/watch?v=-eA6gld0iRY
```

🎧 Скачать аудио
Есть два способа:

Способ 1 — просто отправьте ссылку в чат:

```text
https://www.youtube.com/watch?v=-eA6gld0iRY
```
Способ 2 — через команду:

```text
/download_audio https://www.youtube.com/watch?v=-eA6gld0iRY
```
